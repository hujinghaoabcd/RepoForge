# Desktop application stress suite

These cases verify that desktop README depth is independent from operating-system count, GUI toolkit, extension system, and release infrastructure.

The suite covers:

- a tiny Windows-only utility;
- a Qt scientific workstation for Windows and Linux;
- an Electron offline editor with ordinary multi-platform packaging;
- a mature plugin-capable cross-platform workstation;
- a Full Windows-only application with no plugins, updater, portable mode, or telemetry.

The final case protects the same RepoForge rule used across other families: **Full means deeper documentation, not fabricated capabilities.**

Every stress render also checks the desktop-specific visual contract: centered identity header, meaningful badges, and RepoForge's 280px preview branding.
