# Web Application — Minimal Profile

Use Minimal for a small web product with one dominant local-run path and a small configuration surface.

## Required outcome

A new contributor should be able to answer:

1. What does the application do?
2. How do I run it locally?
3. Which minimum configuration values matter?
4. What is the supported deployment path?
5. Where is the license?

## Expected sections

- product identity and optional screenshot;
- short feature list;
- Run Locally;
- Configuration;
- Deploy;
- License.

## Boundaries

Keep Minimal focused. Do not add architecture diagrams, full API documentation, exhaustive environment-variable tables, infrastructure runbooks, observability, backup, or CI/CD sections unless the project genuinely cannot be operated without that information. In that case, prefer Standard or Full.
