# Web Application — Minimal Profile

Use Minimal for a small but complete deployable web application.

## Goal

A first-time reader should understand the product, see what it looks like, run it locally, know the minimum required configuration, and find the primary deployment path.

## Required sections

1. project identity and one-line positioning;
2. optional screenshot/demo;
3. Features;
4. Run Locally;
5. Configuration;
6. Deploy;
7. License.

## Recommended limits

- roughly 50–110 lines;
- one screenshot or hero image;
- 3–6 product features;
- one main local-development path;
- only the configuration variables required to start successfully;
- one primary deployment path.

## Excluded by default

Minimal should not contain:

- full architecture;
- full database handbook;
- CI/CD;
- observability;
- API reference;
- background jobs;
- large project trees;
- long testing matrices;
- extensive security guidance.

If those are necessary to operate the application safely, choose Standard or Full.
