# Frontend Library — Full Profile

Use Full for mature or broad libraries whose consumer contract includes several distribution/runtime dimensions.

Potential sections include:

- Why, Features, Live Demo;
- Installation and package variants;
- Quick Start;
- API Overview;
- Events and Lifecycle;
- Styling / themes / CSS contract;
- Framework adapters;
- TypeScript support;
- Bundle / tree-shaking behavior;
- SSR behavior;
- Browser compatibility;
- Accessibility;
- Examples;
- Development and testing;
- Release / versioning policy;
- Documentation;
- Contributing;
- License.

Optional sections must disappear when the library does not make that guarantee or expose that capability. Full is documentation depth, not a requirement to support every framework or runtime.
