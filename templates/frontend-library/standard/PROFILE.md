# Frontend Library — Standard Profile

Standard is the default for most maintained frontend libraries and plugins.

Expected sections:

- Why / Overview;
- Features;
- Demo when available;
- Installation;
- Quick Start;
- compact API overview;
- Styling / theming when applicable;
- framework integration when applicable;
- Browser / runtime compatibility;
- Development / Testing;
- Documentation;
- License.

Keep exhaustive props, methods, event payloads, and examples in the documentation site.
