# Research Algorithm — Standard Profile

Standard is the default profile for an original method intended to be read, used, validated, and cited as research software.

## Goal

A reader should understand the scientific problem, the proposed idea, the concrete contribution, the normal software workflow, the validation evidence, and the main limits of interpretation.

## Default structure

```text
Optional logo / method figure
Project name
One-line contribution
Badges / key links

Scientific problem
Method overview
Key contributions
Installation
Quick Start
Validation
Limitations
Documentation
Citation
Support / Contributing
License
```

## Rules

- `Scientific problem` explains the gap, not a full literature review;
- `Method overview` should normally use one compact conceptual explanation, equation, or figure;
- `Key contributions` should contain 2–5 concrete contributions;
- the Quick Start must use the proposed method, not a generic utility around it;
- Validation separates implementation checks from benchmark superiority claims;
- Limitations should state the most important validity or interpretation boundaries;
- detailed derivations, sensitivity tables, and full experiment protocols belong elsewhere.

Target roughly 100–240 rendered lines.
