# Research Algorithm — Minimal Profile

Use Minimal for a focused original method with one dominant operation and a small implementation surface.

## Goal

A reader should understand the method's purpose, install it, run one meaningful example, see the strongest validation statement, and find the citation without reading a paper first.

## Default structure

```text
Project name
One-line method positioning
Paper / code badges                 [optional, light]
Short method statement
Installation
Quick Start
Validation                          [short]
Citation
License
```

## Rules

- keep the method statement to one short paragraph;
- do not add a full literature gap or contribution list;
- one compact equation is allowed only if it defines the output or objective more clearly than prose;
- the Quick Start must be runnable and exercise the actual new method;
- validation should state one or two strongest implementation checks;
- detailed theory and limitations move to Standard when they are needed for responsible use.

Target roughly 45–110 rendered lines.
