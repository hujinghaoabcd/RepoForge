# Desktop Application — Minimal

Use for a small, focused GUI utility or an early but usable desktop product.

Required shape:

- centered identity header;
- meaningful release/platform/build/license badges;
- optional centered screenshot;
- short feature list;
- direct download/install route;
- supported platforms;
- optional run-from-source command;
- license.

Do not add architecture, packaging pipelines, plugin APIs, update channels, or operational detail unless the project needs a deeper profile.
