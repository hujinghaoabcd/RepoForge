# Desktop Application — Standard

Default profile for a maintained desktop application.

Add to the Minimal product flow:

- clearer overview and screenshot;
- download/install matrix by platform;
- first-launch guidance;
- user data/config locations when relevant;
- platform/runtime compatibility;
- build-from-source instructions;
- development/testing commands;
- documentation and contribution routes.

Keep the centered header and badges. Do not turn Standard into a release-engineering manual.
