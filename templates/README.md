# Project-Type Templates

`templates/` contains the semantic README structures for different kinds of repositories.

Initial template types:

```text
scientific-python
research-algorithm
research-experiment
django-package
web-application
frontend-library
desktop-application
```

Each template should eventually contain:

- `README.template.md` — the reusable template;
- `README.example.md` — a complete example output;
- `CONTRACT.md` — audience, required/optional sections, exclusions, and profile mappings;
- `references.md` — selected external reference cases and what was learned from each.

Do not create separate project types merely because a project is small or large. Size and documentation depth belong to `profiles/`.

The first template to be developed is `scientific-python`.
