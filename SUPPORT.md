# Support

This document explains where RepoForge questions and reports belong.

## Repository issues

Use GitHub Issues for:

- reproducible renderer or CLI bugs;
- template output problems;
- documentation errors;
- concrete feature requests;
- project-type/profile design discussions that can be handled publicly.

Repository: https://github.com/hujinghaoabcd/RepoForge

## Before asking

Please check the README, existing issues, project-family `CONTRACT.md` / `PROFILE.md` files, and the corresponding preview when relevant.

For rendering problems, include:

- project type and profile;
- RepoForge version or commit;
- the smallest YAML configuration that reproduces the issue;
- expected and actual output;
- the command you ran.

## Use the right channel

- **Bug or feature work:** follow `CONTRIBUTING.md` and use GitHub Issues.
- **Security vulnerability:** follow `SECURITY.md` and report privately.
- **Conduct concern:** follow `CODE_OF_CONDUCT.md` and report privately.

## Support boundaries

RepoForge is currently an Alpha open-source project maintained on a best-effort basis. There is no guaranteed response time, individualized repository migration service, commercial support agreement, or support for arbitrary private infrastructure unless explicitly documented later.
